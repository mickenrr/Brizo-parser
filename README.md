# Brizo Lead Finder

Веб-приложение, которое автоматически обрабатывает лиды из колонки **«База»** в Brizo CRM:
проверяет финансовые показатели через Checko.ru, заполняет карточки и перемещает подходящие компании в этап **«Парсю»**.

---

## Что нужно для запуска

- **Python 3.10+** — язык программирования, на котором написан парсер
- **Git** — для скачивания кода
- **Аккаунт в Brizo CRM** (sad1.brizo.ru) — логин и пароль от твоего аккаунта

---

## Установка (один раз)

### Шаг 1 — Скачай код

```bash
git clone https://github.com/mickenrr/lead-finder.git
cd lead-finder
```

### Шаг 2 — Установи зависимости

```bash
pip install flask requests beautifulsoup4 python-dotenv PySocks playwright
playwright install chromium
```

> 💡 Если команда `pip` не найдена — попробуй `pip3` вместо неё.  
> 💡 Если команда `python` не найдена — попробуй `python3`.

### Шаг 3 — Создай файл `.env`

В папке `lead-finder` создай файл с именем `.env` (именно так, с точкой в начале).

**Содержимое файла:**

```
APP_PASSWORD=придумай_любой_пароль
BRIZO_URL=https://sad1.brizo.ru
```

`APP_PASSWORD` — это пароль для входа в сам веб-интерфейс парсера. Придумай любое слово, например `parser123`.

> ⚠️ Никогда не добавляй файл `.env` в git — в нём хранятся твои пароли.

---

## Запуск

```bash
python app.py
```

После этого открой браузер и перейди по адресу: **http://localhost:8080**

Там нужно ввести:
- **Логин и пароль от Brizo** — твои обычные данные для входа в sad1.brizo.ru
- **Пароль приложения** — тот, что ты написал в `APP_PASSWORD` в файле `.env`

---

## Как пользоваться

1. Открой **http://localhost:8080**
2. Введи логин, пароль Brizo и пароль приложения
3. Укажи, сколько лидов обработать (например, 50)
4. Нажми **Запустить**
5. Наблюдай за процессом в реальном времени — парсер покажет, какие лиды подходят, какие отклоняет и почему

---

## Логика квалификации

Лид **подходит**, если хотя бы один раз за последние 3 года налог на прибыль ≥ 5 млн руб. и выручка < 1 млрд руб.

Лид **отклоняется** по одной из причин:
- `Нет КД` — нет сайта и корпоративной почты
- `Интересные, но ярд` — выручка больше 1 млрд руб.
- `Маленькая выручка/мало налогов` — налог на прибыль меньше 5 млн руб.

## Часто встречающиеся проблемы

**`python: command not found`**  
→ Попробуй `python3 app.py`

**`pip: command not found`**  
→ Попробуй `pip3 install ...`

**`ModuleNotFoundError: No module named 'flask'`**  
→ Зависимости не установлены. Повтори Шаг 2.

**`playwright install chromium` зависает или выдаёт ошибку**  
→ Попробуй `python -m playwright install chromium`

**Браузер не открывается / сайт недоступен**  
→ Убедись, что в терминале нет ошибки и скрипт запущен. Попробуй адрес `http://127.0.0.1:8080`

**Parcer запускается, но Brizo выдаёт ошибку авторизации**  
→ Проверь логин и пароль — убедись, что можешь войти в sad1.brizo.ru вручную через браузер
